# 丁浩轩 · 个人网站

React + Vite 单页网站，黑灰底色和银色细节，PC 版心最大 1700px；适配手机和平板。当前为本地可运行版本。

## 运行与构建

```bash
npm install
npm run dev
npm run build
npm run preview
```

本地开发默认地址为 http://127.0.0.1:5173/。双击项目中的“启动网站.cmd”，会在后台启动网站，等待页面就绪后自动打开浏览器；关闭启动窗口不影响访问。重复双击会打开已运行的网站。重启电脑后需再次双击启动。启动日志保存在 .previews/server-output.log 与 .previews/server-error.log，首次缺少依赖时会自动安装。构建输出为 dist/，可部署到支持单页静态网站的主机。

## 内容与结构

- src/content.js：姓名、联系方式、简介、项目、经历和能力文案。
- src/App.jsx：页面结构、项目筛选、原生详情弹窗、联系方式、复制与视频控制。
- 精选作品使用可展开、收起的卡片，默认展示轻量缩略图和标题。展开后显示完整图片与介绍，点击大图可查看作品详情；作品直达链接会自动展开对应卡片。
- src/RotatingPortrait.jsx、src/rotating-portrait.css：关于我中的立体相片展示，可左右拖动、使用方向键或角度滑杆旋转，提供自动旋转与复位。背面为姓名标识；离开画面或切换标签后暂停自动旋转，尊重系统减少动态效果设置。
- src/DriftWall.jsx、src/DriftWall.css：接入用户提供的 React Bits 漂浮照片墙，适配本地图片、悬停抬升和视差，支持手动暂停、离屏及后台暂停。
- src/LifeGallery.jsx、src/life-gallery.css：生活切片、平铺浏览和原图灯箱。9 张不同的生活与收藏图片配置在 src/content.js 的 lifePhotos 中，原图与轻量预览位于 public/images/moments/。系统减少动态效果时默认平铺。
- src/styles.css：视觉系统、动效、各屏幕断点与 1700px 版心。
- public/images/：用户提供的照片和 MJ 作品，以及先前制作的概念示意素材。
- src/AeroShards.jsx、src/HeroShards.jsx：首页银灰色铬质碎片动效，通过 vgpu 使用 WebGPU；按需加载，支持暂停与减少动态效果，不支持 WebGPU 时使用轻量 CSS 碎片。旧视频素材仍在 public/video/ 中备用。

页面按人像与银灰碎片开场、个人 MJ 作品、个人背景与经历、生活切片照片墙、不同侧面、整屏联系页展开。精选作品与视觉实验可切换；四份概念提案均标有“概念示意”。AeroShards 已适配 vgpu 0.6 的 ShaderSource v2 接口，片段着色器通过 @vgpu/wgsl/prepare 准备。
